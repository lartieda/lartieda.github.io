# Luis Artieda Portfolio

Personal portfolio for bioinformatics, data science and machine-learning roles.

## Publish with GitHub Pages

1. Create a public GitHub repository named `lartieda.github.io`.
2. Upload the contents of this folder to the repository root.
3. In the repository settings, open **Pages** and select **Deploy from a branch** with the `main` branch and the `/ (root)` folder.
4. The portfolio will be available at `https://lartieda.github.io` after deployment completes.


## Local preview

Open `index.html` in a web browser.
